## 1. 定位与设计支柱



| 项       | 内容                                 |
| ------- | ---------------------------------- |
| 游戏名（暂定） | 《六 8 班异闻录》                         |
| 类型      | 剧情驱动 SRPG + 轻自由探索（GBA / 火焰纹章式回合战棋） |
| 核心幻想    | 小学生用文具、知识和操场家伙事儿，对抗 "诱惑童年" 的神秘力量   |
| 目标情绪    | 悬疑 → 紧张 → 温暖（守护同学与童年）              |
| 游戏节奏    | 探索（自由活动 + 对话）↔ 战斗（FE 回合制）交替        |
| 单章时长    | 约 40–60 分钟 / 章                     |

**设计支柱（一切决策的依据）**



1. **悬疑先行**：信息分层披露，前期只给 "反常"，不给 "答案"。

2. **FE 式决策**：数值可见、风险可读、每回合有选择。

3. **双线复玩**：男女主仅第一章初始三人组不同，第二章起剧情合并；两章信息互证，二周目有新鲜感。

4. **反差恐怖**：用小学生最日常的东西（作业、零食、考试、体测、互相告状）变怪来制造氛围。

5. **主题克制**：不喊口号，用故事讲 "别让焦虑和攀比吞噬童年"。

## 3. 故事与世界

### 3.1 核心谜团（分层披露）



| 层  | 玩家知道什么                                     | 披露时机       |
| -- | ------------------------------------------ | ---------- |
| 表层 | 同学突然 "反常地拼命"（学超龄知识、做成人级训练），行为怪异            | 第一章        |
| 中层 | 与校外可疑人有关，存在统一 "媒介物"（荧光零食 / 运动饮料，同一个怪 logo） | 第一章末 → 第二章 |
| 暗层 | 学校里也有人在分发 / 默许（王主任桌上的饮料、黑影女子、徐老师藏瓶子）       | 第二章末 → 第三章 |
| 深层 | 魔物真身、为何选中六 8 班、黑影女子是谁、徐老师站哪边               | 预留，后期章节    |

### 3.2 核心设定（定死，别改）



* **魔物**：没有实体怪物，就是 "想变厉害、怕被比下去" 这个念头本身。它不钻进脑子，它在你心里等你自己伸手。**恐惧、猜疑、攀比本身也会喂养它**（第三章主题）。

* **媒介物**：荧光零食 / 荧光运动饮料，同一个发光怪 logo，换包装出现。

* **散播者**：校门口推小车的青白脸大叔，第一章被打跑，只是跑腿的。

* **"它们"**：受害者嘴里的词，全程不解释，每次出现都冷一点。注意是 "它们" 不是 "它"。

### 3.3 贯穿钩子清单（从第一章埋到结尾，不许提前回收）



1. **那包零食**：第一章桌上那包，之后每章换皮出现。

2. **学酥的歪念 + 吃没吃**：主角盯着零食想 "吃一口就能考高分吧"。第一章末**留白不演**；第三章**回收**—— 主角其实没吃、把它扔了（成为洗清冤屈的物证），但主角 "曾经动摇过" 的心理要保留。

3. **徐老师捡瓶子**：第二章末她一声不吭把空运动饮料瓶塞进自己包，不上交。为什么？

4. **教务处黑影女子**：第二章末窗帘后的女人影；第三章末与徐老师夜会。她是谁？

5. **学校里有人**：饮料 / 零食不是校外随便发的，学校领导桌上也有。

6. **"它们下周还要来"**：第一章恢复者说漏嘴，预示危机是持续的、一波接一波的。

* **只有第一章分男女线**，差异仅限：主角、初始队友（张瀚瑜 / 陈品璇）、失踪者（范文默 / 何妍熹）、对应台词与道具（物理书 / 单词卡、竖笛）。

* **从第二章进操场起，两条线走同一套剧情、同一批角色与战斗**，只把主角立绘 / 名字换成当前周目主角；不再产出差异化角色。

### 4.2 自动存档记录点（Checkpoint）规则

**以下四类节点必须各埋一个自动存档点（无需玩家手动）：**



| 类型                         | 触发时机                                        | 对应 story pipeline 字段 / 研发动作                             |
| -------------------------- | ------------------------------------------- | ------------------------------------------------------- |
| **CP\_SCENE** 场景切换         | 每进入一个新场景（新背景 / 新对话段）                        | 加载新 scene 对象后写档                                         |
| **CP\_BATTLE\_START** 战斗开始 | 玩家确认进入战斗、战斗地图加载完成                           | `transition.isBattleTrigger === true`、读到 `battleId` 时写档 |
| **CP\_BATTLE\_WIN** 战斗结束   | 战斗胜利结算（发经验 / 掉落）完成后                         | 战斗胜利回调、回到剧情前写档                                          |
| **CP\_CHAPTER** 章节切换       | 章节标题卡 / `type: 'CHAPTER_CLEAR'` / 进入下一章第一场景 | 章节转场时写档                                                 |

**实现约定【代定，研发可调整】**



* 存档数据至少包含：`chapterId`、`sceneId`、`line`（male/female）、`party`（已入队角色与等级）、`inventory`、`flags`（剧情开关，如 `snack_thrown`、`saw_shadow`）、最近一次 checkpoint 类型。

* 战斗失败：序章教学战 = 回安全区重来（友好）；正式战斗失败 = Game Over，读最近的 CP\_BATTLE\_START。

* CP\_BATTLE\_WIN 与紧随其后的 CP\_SCENE 相邻时，可合并为一次写档，避免冗余。

* 每章末的 CP\_CHAPTER 是 "章节完成档"，用于章节选择 / 回看。

## 10. 对话写作规范（幽默 × 悬疑 × 小惊悚）



* **配比**：70% 幽默松弛 + 20% 悬疑暗流 + 10% 惊触点刺。日常越松，异常越冷。

* **单段 ≤ 3–4 句**，小学生口吻（11–12 岁用词），不许成人腔 / 书面腔；"合作单位"" 教育局检查 "这类大词改成" 上头来人 ""学校发的"。

* 幽默来自人设（子骁嘴贫、瀚瑜胆小脑补、品璇护短、希哲热血、瑞怡元气、朱晏泽冷幽默、徐老师冷面藏关心），不来自段子。

* 每段日常藏一个 "不对劲"，用最平常的语气说最异常的事，绝不当场解释。

* 惊触点靠节奏骤停：搞笑句后突然一句冷话 + BGM 停 + 立绘切异变（≤0.8s，做 "心里一凉"，不做 jumpscare）。

* 心理活动用（）括起、不同颜色；复现词 "它们" 每次出现都降温；**笑完必须留一个 "但是……"**。

* 大人的话越日常越吓人："为你好"" 来得及 ""别人都在学"" 为你将来打算 "。
