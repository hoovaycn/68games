# 技能 Buff / Debuff 视觉资源需求清单

> 背景：技能系统已接入战斗，buff/debuff（治疗/增益/减益/伤害）目前只有文字浮字提示。为让玩家一眼看懂「中了什么效果、怎么个意思」，需要补充**状态图标**和**释放特效**。
> 出图规范：统一 **像素风、硬边、洋红 #FF00FF 底**（后期色键抠图），与项目立绘/道具图标同管线；每个图标出 **16×16 基础版 + 32×32 @2x 版**。

| 反馈 | 现状 |
|------|------|

## 三、需出图：技能释放特效（可选，优先级低于状态图标）

释放技能瞬间的像素光效，时长约 0.3~0.5s：

| 特效 | 用途 | 建议表现 |
|------|------|----------|
| 治疗光环 | heal 类 | 绿色十字 / 上升光点，目标头顶扩散 |
| 增益上升 | buff 类 | 金色 ↑ 箭头粒子，从目标脚下上升 |
| 减益下降 | debuff 类 | 红色 ↓ 箭头 / 暗色雾气下沉 |
| 技能命中 | damage 类 | 沿用现有受击闪白即可（无需新图） |

> 若为了赶进度，特效可以**先不做**，只用「浮字 + 状态图标」已经能传达效果；特效是锦上添花。

1. **先出 12 个状态图标**（第二部分）→ 战斗里单位头顶挂图标，buff 一眼可见。
