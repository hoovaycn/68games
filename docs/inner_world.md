# 《六8班异闻录》· 里世界设定（暗面卷 / 精神主线）

> 这份文件写的是**里世界**——藏在学校剧情（表世界）底下的真相、规则和精神主线。
> - **表世界**（写在 `gdd.md`）：玩家看到的明线——谁被异化、谁来救、打哪一仗、钩子埋哪。
> - **里世界**（本文件）：为什么会这样、这东西多少年了、谁受益、谁在害人、为什么只能孩子们自己赢。
> - 本文件含**全篇底牌与剧透，对玩家保密**，仅供编剧 / 美术 / 研发统一精神口径。
> - 对话与演出仍守小学生能懂的大白话；这里写得深，是为了让表面的故事"底下有东西"，不是让角色把道理讲出来。

---

## 〇、一句话精神主线

**这世上没有幕后黑手，只有一群怕被比下去的人；递东西的手和接东西的手，长在同一群人身上。**

孩子们以为自己在跟"一包害人的零食"和"一个下毒的坏人"斗，越查越发现：那东西不害人，它只是**成全你**——成全你想立刻变厉害、想被夸、想赢、想不被落下的那点心思。真正要打赢的，是"想走捷径、还想让别人替自己的选择负责"的那个念头。这个念头在每个人心里，也在每一代人心里，所以它几年回来一次，几十年都杀不死。

---

## 一、什么是"里世界"

- **表世界的问题**是："这次是谁中了招？东西是谁给的？"——每一章都有具体的人、具体的仗。
- **里世界的问题**是："为什么总有人接？为什么查不到源头？为什么十几年了一模一样？"
- 玩家前期只在表世界玩，靠黑影女、旧物、调查，**一层一层摸到里世界**：
  1. 表层：同学反常地拼命（第一章）。
  2. 中层：校外可疑人 + 统一的异化零食（一末～二章）。
  3. 暗层：学校里也有人分发 / 默许（二末～三章）。
  4. 里层：没有分发者，没有组织，东西是普通的东西——**源头是念头本身，是一场持续多年的轮回**（中段以后揭开）。
- 反转的快感来自"同一批证据的两种读法"：徐老师、黑影女所有像"密谋害人"的举动，揭到里世界后全部重读为"在救人"；而玩家以为存在的"大阴谋组织"，揭到最后**空无一人**。

## 二、统一叫法与识别标记

- 所有换皮媒介，**书面统称「异化零食」**；罐装 / 瓶装的叫**「异化饮料」**；不是食物的（押题卷、好运笔、聪明牛奶、能量胶等）统称**「异化的东西」**。
- 孩子口语里不叫学名，叫"那糖""那饮料""那玩意儿"，带着忌讳，不敢全名说。
- **唯一不变的识别标记：包装上那个发光的怪 logo**。十几年里外形、品类、牌子换了无数版，logo 和那层荧光始终一样。
- 它越来越"正经"：校门口三无烤肠 → 网红零食 → 运动饮料 → 押题卷 / 名师 U 盘 → 印得像学校发的、像正规机构发的。**越像"大人认可、官方发放"，越危险。**
- （研发 / 美术口径：道具命名统一走 `corrupted_xxx` 或异化系列；非食物异化物品与食物共用同一套荧光 + logo 视觉语言。）

## 三、真相：这是一场"真有效"的交易

别把异化零食写成毒药、假货或恶作剧——那太轻，也撑不起道德悖论。

它是一场**公平得可怕、还真有人觉得值的交易**：

- 吃了，**真的会变好**。短期成绩蹿升、训练出成绩、考级过关、当众被夸。不是幻觉，是实打实的"受益"。
- 代价是**"出"掉自己的"息"**：一点一点交出会笑、会玩、会发呆、会喜欢没用东西的那部分，变成一个不会累、不会停、也不再是"自己"的空壳。游戏里管这叫"异化"，孩子的话说就是"变了个人"。
- **没有"白拿好处还完整"的第四种结局**。交易是真的，代价也是真的，选不选、值不值，全在本人。
- 正因为它真有效，它才无法被简单拒绝——"明知有害的毒药"谁都能拒绝，"能让你立刻不被人比下去、而且大家都在用"的东西，才考验人。

> 叙事口吻示例（里世界揭开时可以有的旁白感，不直接念给玩家）：
> "它从来不骗你。它只是把你想要的东西，真的递给你，然后安静地等你自己松手——松开那个笨笨的、慢慢的、会输的你自己。"

## 四、四个道德悖论（精神主线的核心，剧情反复围绕它们转）

### 悖论一：是别人给的，还是自己想要的？
- 东西确实是别人递来的（大叔、同学、"学校发的"），可它**从不强迫人**，最后伸手的是自己。
- 但一个十二岁的孩子，被家长、老师、排名、"别人家的孩子"天天催着赢——这"自己想要"里，又有多少是被吓出来的、被比出来的？
- 游戏**不给标准答案**，让玩家带着这问题走到终章。主角最后的回答是破局钥匙，大意：
  > "就算全世界都在催我，最后伸手的是我；那最后能把手缩回来的，也只能是我。"
- **魔物最怕人承认"是我自己想要"**——因为一旦承认，就没法再说"是它害我、是别人逼我"，推卸不掉，它就断了粮。

### 悖论二：有人因此受益，有人再也回不来
- 用了的人里，有的成功后靠自己站住了、慢慢把魂养回来；有的成功了，却再没变回会笑的人（黑影女的同桌、"优秀学长"那面镜子）。
- 谁也不能替当事人判断"值不值"。这让故事不说教、不简单：努力不可耻，想赢不可耻，**丢人的是抄近道抄成一个假的自己**。
- 但要让玩家隐隐感到：你才六年级，你根本不知道自己交出去的是什么。

### 悖论三：受害者，就是下一个加害者
- 这是轮回真正的发动机，也是最冷的一条。
- 被异化、又"成功"了的人，长大后往往真心相信"我当年就是这么过来的，不逼不成器"，于是变成递东西、逼下一辈的人——家长、老师、教练、卖课的、回来演讲的状元。
- 他们不是恶人，他们是**活下来的受害者**，在用自己被对待的方式对待后来者。
- 超自然层的对应（见第五节"它们"）：**每一个伸手选了捷径的人，都会成为下一个人脑子里的一个声音。** 你以为你只吃了一口糖，其实你加入了"它们"。

### 悖论四：连善意和义气，也能被它利用
- 它不只喂养贪婪，也喂养"为你好"：家长的操心、老师的负责、同学"好东西分享给你"的热心。
- 它甚至能利用**最珍贵的义气**：一个平时最靠谱、最护着同伴的孩子，为了"不拖大家后腿""我要变强保护你们"，主动去碰异化零食（自我牺牲式倒下）。
- 这让"好人会不会中招"有了悲剧答案：**会，而且越好强、越懂事、越怕连累别人的孩子，越容易被它从这道口子钻进来。**

## 五、"它们"到底是什么（保持半遮半露，不一次说死）

- 表世界全程不解释"它们"，只让受害者用这个词（注意是"它们"不是"它"），每出现一次，温度降一度。
- 里世界的底牌（后期才让玩家拼出来）：
  - 它不是鬼、不是妖怪、不是某个人，**没有独立人格**。
  - 它是**古往今来所有"选择走捷径那一瞬间"的总和与回声**——一股由"怕输、想快、想被认可"堆起来的集体念头。
  - 受害者脑子里听到的"不是一个，是好多个"声音，是一届届选过捷径的人留下的回声在催他："再学一点""别停下""输了就完了"。
  - **你一旦伸手，你那句心声也会变成后来者脑子里的一个声音。** 受害者与加害者因此在超自然层也是同一批人——这就是"它们"为什么用复数、为什么十几年不散。
- 它**不撒谎，只放大你最怕的真话**："你确实不如他""考砸了就没人喜欢你""你妈妈是不是更喜欢你弟弟"。最狠的是它说中了你心里最虚的地方。
- 终章大考、压力到顶点时，这股念头唯一一次聚成看得见的形体——**一个没有脸的荧光影子**（"它们"的集合体）。它不是最终 Boss 那种"打死就通关"的敌人，而是要靠全班集体选择让它**失去养料、自行溃散**。

## 六、轮回：几年一次，已经很多年了

### 规律
- 它不是第一次来，也不会是最后一次。**每隔几年，卡在升学 / 大考压力最盛的那一年，它就复发一次**；压力最肥的毕业班（六年级、初三、高三）是重灾区。
- 每一届的表现**惊人地一致**：同一个发光 logo、同一套"吃了就能赢"的话术、同一次对准大考的爆发、同一句"是别人给我的"。
- 黑影女追了它十几年，画了一张跨年份的传播图，得出最瘆人的结论（第四章末的新钩子）：
  > "我本来也以为是人在害人……可一个人，没法连着做十几年，还每次都一模一样。我追了它十几年，从来没找到过那个'发东西的人'——每一个，都说是别人给的。"

### 十几年前那一届（黑影女的旧案，第四章真身浮现时娓娓道来）
- 黑影女**曾经就是这所学校这个年级的学生**。她和同桌是最好的朋友。
- 同桌永远是全班第二，总被拿去跟第一比。大考前，同桌拿到了"能考第一的东西"，黑影女劝过，没劝住。
- 考完，同桌考了第一，却**再也不会笑、不会玩，像个只会做题的人**，没多久就转学了，再没回来（不写死、不恐怖化，用"变了个人"的后劲让人发凉）。
- 黑影女自己当年**也动摇过、差点伸手**，是还清醒的同桌按住了她——她和主角是镜像：都是"差点伸手、最后没伸"的人。她一直愧疚，觉得当年该被救回来的是同桌。
- 当年没有一个大人信一个小孩说的"零食中邪"。于是她长大、改名，追着复发的学校走了十几年，这学期以**新来的校医**身份回到这所学校。校医室是她的据点，也是第四章真相大白的主场。
- 她不是超人，她清楚自己的边界（见第八节）：**大人的话它不听，她只能蹲守、记录、暂时压住，真正能把人拉回来的，只能是孩子自己和孩子的同伴。**

### 徐老师（暗线，与黑影女互为表里）
- 徐老师是**第一个肯信黑影女、肯陪她救孩子的大人**。她捡瓶子、收零食不上交、锁抽屉、和黑影女夜会、盯着主角欲言又止——表世界全是"可疑罪证"，里世界全是救人：
  - 不上交，是因为学校里有人默许，交上去会被当成没发生过、还会打草惊蛇。
  - 一抽屉媒介 + 写满名字的纸，是**物证和"接触者观察记录"**，不是下手名单。
  - 黑影女给她的发光小瓶，是发作时让孩子先安静、别伤到自己的**镇定瓶**（真正起效的其实是陪伴，见第八节）。
  - 她总第一时间赶到，是在蹲守；她压着事情不声张，是知道一恐慌就互相猜疑，而猜疑正是它的饲料。
  - 她盯着主角看，是看出这个学酥也动摇过，在赌主角是不是那个"自己扛住、还能带大家一起扛住"的孩子。
- 【待定 / 可选】徐老师自己的执念：她**不是**当年的学生（那身份专属黑影女，不重复）。可埋她刚当老师时曾一味逼成绩、眼睁睁看过一个孩子崩溃，从此转变，所以这次死也要护住人。轻埋、不抢戏，待拍板。

## 七、谁受益：一台没有司机的机器

### 一张无心的网
顺着"谁给的"往上查，会摸到一条利益链，每一环都只是普通人、都只走了一小步"对自己有利"的路：

| 环节 | 得到的好处 | 心里的话（没人觉得自己在作恶） |
|---|---|---|
| 用了的孩子 | 名次、分数、被夸、不被落下 | "我只是想变好" |
| 好心分享的同学 | "我够意思、我带着朋友一起" | "好东西当然分给你" |
| 家长 | 孩子有出息、自己有面子 | "我都是为你好" |
| 老师 / 学校（含默许者） | 成绩、升学率、评比 | "不能让咱们班 / 咱们学校输" |
| 卖货 / 卖课 / 跑腿的 | 挣钱 | "我就是做个生意" |
| 整个风气 | —— | "别人都这样，你不这样就吃亏" |

- 这些小步合起来，像一台精密运转、专在大考前把异化零食递到孩子手里的机器；**可这台机器没有司机、没有总部、没有主谋。**
- 统一的 logo 和话术不是谁统一印发的，是每一届被焦虑填满的人**在恍惚中照着脑子里的样子自己复刻**出来的——念头靠人心自我复制、自我传播，异化零食只是它借用的壳。
- "谁干的"终极答案：**不是谁。是"怕被比下去"这件事本身。** 阴谋根本不需要阴谋家，系统会自己长出一模一样的结果。
- 调查线可以安排一次"假黑手"高潮：终于抓到一个活人（推车大叔回来了，或个卖"提分神药"的骗子），结果黑影女早化验过——**他卖的就是普通糖**；抓了他，第二天东西照样出现在学生手里。亲手证明"抓坏人没用"，玩家才会信根子不在某个人。
- 学校里"有人默许 / 领导桌上也有饮料"这条暗线，处理为**被升学率焦虑裹挟的普通大人**即可，不立固定反派、不设 Boss，避免把"没有黑手"的主题又拉回"打倒坏人"。

### 三种结局（塑造角色和"镜子"用，没有第四种）
1. **用了、成功、也站住了**：表面的赢家，心里可能空了一块，或选择遗忘；长大后往往成为继续催下一代的人——轮回的燃料。
2. **用了、成功、却回不来**：黑影女的同桌；以及【待定 / 建议】学校请来演讲的**"优秀学长 / 状元"**——西装革履、人生赢家，说的话却和异化者一模一样（"输了就什么都没了""我感谢当年拼命的自己"），某个瞬间眼里 / 桌上闪过异化的光。他是**"赢了，也可能是输了"的活镜子**，只用一个象征性成年人、不进战斗、不堆家长群像。
3. **没用、慢、但保住了自己**：主角团、黑影女。会输、会普通、会被比下去，但还是个完整的、会笑的人。

## 八、里世界的规则（直接指导剧情与战斗机制）

- **媒介只是引子，不是病因。** 前期靠吃 / 喝传播；后期压力到了，**没吃没喝也会被猜疑、攀比、恐慌"点着"**（情绪人传人，第三章互相猜疑已埋）。所以"收缴零食"治标不治本。
- **它靠什么喂养**：恐惧、猜疑、攀比、推卸责任、"为你好"的压力、怕不被喜欢。越恐慌、越互相指认、越说"是别人害我"，它越强。
- **它怎么被削弱**：被看见、被说出真名、承认"是我自己想"、知道"无论我考几分都有人要我"、同伴不肯松手。
- **为什么只能孩子自己赢**：它不听大人的道理，只应孩子心里那句欲望。大人（徐老师、黑影女）能做的是**信、陪、护、蹲守、铺路、暂时压住**，但**没法替孩子选择、替孩子出手**——这就是黑影女说的"要赌上这些孩子自己"。
- **镇定瓶的真相**：物理效果存疑（黑影女自己也不确定），真正让发作孩子安静下来的，是"有个大人相信你、陪着你、不把你当怪物"。这是给"大人的作用"留的位置：大人不能替你打，但大人的相信是孩子敢出手的底气。
- **救一个人不是"打死"他，是"喊回"他**：战棋上可以表现为走到同伴身边、撑过若干回合、当面喊名字 / 提一件"你本来是谁"的事。最破防的一句是切断它"不被喜欢就完蛋"的供能，大意：**"你考零分我也跟你玩。"**
- **每个异化 Boss 的机制 = 他的执念**：控制狂靠谣言层数、完美学生越被夸越强（要让他听见"你不用完美"）、拼命练体育的拖越久越自残（要打断）、自我牺牲的队友要靠最铁的人近身喊回。
- **终章"拉人连锁"**：被荧光困住的同学散在地图上，走到身边、用前几章攒下的交情拉回来；每拉回一个，无面影弱一块、我方多一人——前几章救过的人全部回来帮忙，玩法和主题合一。
- **它杀不死**：想变好、怕落后是人之常情，消灭不了。能做的是**在自己这一代把轮回踩停一次、断掉一环**，并让被救回来的人以后别再去逼别人。

## 九、终局在里世界的意义

- 大考当天，集体压力到临界点，"它们"聚成唯一一次具象的无面荧光影；同时低语、媒介、残余的分发一起制造最后一次大爆发。
- 高潮不是打败某个恶人，而是：
  1. 战棋上顶住、拉住一个个同伴（拉人连锁）；
  2. 学酥主角（自己也动摇过、那包零食一直没吃）当众承认"我也想过走捷径"，再说出"但我选不"；
  3. 全班一个个小声说出自己的怕（"我怕考不好""我怕我妈失望""我怕你们不带我玩"）——**说破了，它就没劲了**；
  4. 众人一起放下手里的异化东西，无面影失去养料，自行溃散。
- 这不是拯救世界、消灭邪恶，是**一群孩子给十几年的轮回踩了一脚刹车**：救不回已经变了的人，但能让自己、让身边的人，不变成那种大人。
- **开放尾镜**（温暖但不闭合）：另一所学校 / 下一届，一包静静发光的零食躺在角落，一只小手伸过去，停了停，又缩了回来。字幕大意："它还会来的。没关系，我们会选了。"

## 十、里世界 → 表世界的映射守则（编剧 / 关卡 / 美术统一口径）

- **每一章的异化学生 = 一种"怕被比下去"的切面**（分数、班干部、特长考级、校队、朋友反目、完美学生、小升初……），从表世界看是一个个独立事件，拼起来是里世界的全貌。
- **每一次"反转"都是剥掉一层外因借口**：怪零食 → 怪大叔 → 怪学校 → 怪那个"她"……剥到最后让玩家面对"是自己心里那一下"。别让任何一个具体反派替玩家背走这个问题。
- **徐老师、黑影女的所有可疑动作，必须在表世界先按"像害人"演足，里世界再按"在救人"重读**，同一批证据、两种读法，反转才成立。
- **异化视觉统一语言**：同脸同衣、青蓝发光眼、冷笑或空洞、冷青调，**不怪物化、不长异物**；真正"不像人"靠表情、动作和"说大人话"，不靠外形变怪兽。
- **"它们"相关的字体 / 音效每次复现降温一度**；无面荧光影的形象要到终章才给全，前期只用反光里的影子、齐刷刷转头、排名榜名字变淡等惊鸿一瞥。
- **配比**：表世界七成幽默、两成悬疑、一成惊触，笑完留一个"但是……"；里世界的沉重通过悬念和反转渗出来，角色台词始终是孩子的大白话。

## 十一、红线（不做什么）

- 不设"幕后大反派 / 大魔王"，不把锅甩给某个坏人或某个组织——一甩，精神主线就塌了。
- 不妖魔化"努力、学习、考好、特长、大人的操心"；要反对的是"用灵魂换捷径"和"逼别人也换"，不是反对上进。
- 不引入家长群像、不做魔化家长 Boss；大人只保留徐老师、黑影女、推车大叔，外加至多一个象征性的"成年人镜子"。
- 不让主角团靠外力 / 靠大人替他们打赢；大人铺路，选择和战斗必须是孩子的。
- 不给"从此天下太平"的完美结局；它杀不死，只能一次次被打断。
- 不把道理写成角色嘴里的说教；道理靠事件、选择和反转让玩家自己得出。
