# 《六 8 班异闻录》纯前端战棋 —— 架构设计文档

> 状态：v0.4（2026-09-15）・游戏名暂定，可改（v0.4 新增武器系统、美术资源管线、音频系统）
> 本文档是活文档，随故事、角色设定和迭代持续更新。



***

## 1. 项目定位



| 项    | 内容                                     |
| ---- | -------------------------------------- |
| 类型   | 剧情驱动 SRPG（战棋）+ 轻自由探索                   |
| 平台   | 纯前端 Web（浏览器运行，无后端）                     |
| 画风   | 像素风（FE GBA 风格），现代校园题材                  |
| 题材   | 小学生 × 现代校园 × 悬疑异变                      |
| 玩法核心 | 自由探索（对话 / 明雷遇敌）+ FE 回合制战斗 + 角色成长 + 多章节 |
| 存档   | 浏览器 localStorage（双线独立存档）               |

## 2. 需求基线

### 已确认（硬约束）



* 纯前端，像素画风，火焰纹章式战棋（网格、回合、行动力、角色培养、完整战斗系统）

* 多地图 / 章节切换，有不同 NPC 角色

* 故事设定：现代校园（人大附小・六 8 班），小学生在校园内外对抗 "让人走火入魔" 的神秘力量（悬疑向，信息分层披露）

* **角色选择 + 双线叙事**：男主张子骁（练字）/ 女主石予诺（背单词），双线共享序章骨架、角色与线索互异

* **自由活动**：安全区（校园）内自由走动、与 NPC 对话

* **明雷遇敌**：危险区（校外）敌人可见于地图（巡逻 / 警戒），接触触发战斗，可绕行

* **对话演出**：左右半身立绘 + 对话框 / 气泡（FE 风格）+ 头像小框

* **美术规格**：FE GBA 风格头像 96×96、半身立绘 240×320、行走图、战斗动画

### 待用户补充（占位，不阻塞架构）



* 章节总数与后续章节场景

* 魔物真身、幕后设定（悬疑深层）

* 战斗模式偏好（经典：阵亡永久 / 休闲：退场下一章回归）

* 队伍规模（后续章节是否组队）

## 3. 技术选型



| 层  | 选型                     | 理由                                                                     |
| -- | ---------------------- | ---------------------------------------------------------------------- |
| 渲染 | **原生 Canvas 2D**       | 像素风天然适配（`imageSmoothingEnabled = false`）；战棋渲染需求简单（瓦片 + 精灵 + UI），无需重型引擎 |
| 语言 | JavaScript（ES Modules） | 零构建心智负担，浏览器直接可跑                                                        |
| 工程 | Vite（可选，开发服务器 + 打包）    | 热更新调试；纯静态产物可任意部署                                                       |
| 数据 | JSON/JS 配置驱动           | 所有内容（地图、角色、敌人、剧情、双线差异）与引擎解耦                                            |
| 存档 | localStorage           | 章节解锁、队伍状态、道具、双线进度                                                      |
| 音频 | Web Audio / 预生成音效      | 像素风 BGM/SFX，悬疑氛围音效                                                     |

> 备选：若想更快出成品可换 
>
> **Phaser 3**
>
> （内置场景、瓦片地图、输入、补间动画），代价是学习框架约定、自定义 UI 自由度略低。当前推荐原生 Canvas，逻辑可控、最贴合像素风。

## 4. 总体架构（分层）



```
┌─────────────────────────────────────────────┐

│  表现层 Renderer & UI                         │

│  Canvas 像素渲染（瓦片/精灵/动画/伤害数字）      │

│  输入（键鼠/触屏）│ HUD │ 信息面板 │ 菜单 │ 对话  │

├─────────────────────────────────────────────┤

│  玩法系统层 Systems                           │

│  场景管理 │ 网格寻路 │ 回合管理 │ 战斗结算 │  AI  │

│  经验成长 │ 事件剧情 │ 存档                      │

├─────────────────────────────────────────────┤

│  内容与数据层 Data（JSON 配置）                 │

│  章节地图 │ 角色职业 │ 魔物图鉴 │ 道具 │ 对话脚本 │

│  双线路由(male/female) │ 头像立绘素材            │

└─────────────────────────────────────────────┘
```

数据流方向：`输入 → 玩法系统（读配置、算结果）→ 渲染`；`战斗/剧情结果 → 存档 → localStorage`。

## 5. 核心系统规格

### 5.1 引擎层（engine/）



| 模块    | 职责                                                    |
| ----- | ----------------------------------------------------- |
| 主循环   | 固定时间步 update + render；暂停 / 恢复                         |
| 场景状态机 | 标题 → 角色选择 → 自由活动 (安全区) → 危险区 → 战斗地图 → 对话演出 → 结算 → 下一章 |
| 输入    | 统一键鼠 / 触屏，转成游戏指令（移动 / 交互 / 点选 / 确认 / 取消）              |
| 相机    | 跟随、缩放，适配大尺寸地图                                         |

### 5.2 网格与寻路（grid/）



* 地图 = 二维数组瓦片，瓦片类型：地板、墙壁、障碍、地形（掩体）、据点

* 地形加成表：`terrain: { "课桌": {def:1, avoid:10}, "花坛": {def:0, avoid:15} }`

* 移动范围：BFS 按移动力扩散（含地形移动消耗）

* 攻击范围：按武器射程生成（近战 1 格 / 远程 1-2 格）

* 寻路：A\*（敌人 AI 追击用；范围扩散本身用 BFS）

### 5.3 单位系统（units/）



* 属性：HP / 力量 / 魔力 / 技巧 / 速度 / 幸运 / 防御 / 魔防 / 移动

* 职业：基础属性 + 成长率 + 可转职（数据驱动）

* 阵营：我方 / 敌方 / 中立 NPC

* 状态：中毒、睡眠、魅惑等（可选，P1 再上）

* 成长：经验 → 升级 → 属性随机成长（按成长率）→ 转职

### 5.4 战斗结算（combat/）

简化自 FE 成熟公式，初值如下（可调）：



```
物理伤害 = 力量 + 武器威力 − 敌方防御

魔法伤害 = 魔力 + 魔法威力 − 敌方魔防

攻速 AS  = 速度 − max(0, 武器重量 − 体格)      // P0 可先省略重量

回避     = AS × 2 + 幸运 + 地形回避

命中率%  = 武器命中 + 技巧×2 + 幸运÷2 − 回避

追击     = 攻速差 ≥ 5 时，二连击（先手方判定）

必杀率%  = 武器必杀 + 技巧÷2 − 敌方幸运

经验     = 30 + 等级差×5（我方高于敌方递减，最低 1）
```



* 战斗前 UI 预览：红 = 可击杀、黄 = 会受击、绿 = 安全（FE 经典交互）

* 武器三角克制（可选，P1）：文具 / 书本 / 零食…（等设定再定）

### 5.5 敌人 AI（ai/）



* 每回合决策：**找目标 → 能打就打（优先可击杀→最低 HP→最近）→ 打不到就朝目标移动 → 待机**

* AI 参数化：攻击性 / 是否回血 / 是否守点，配置在敌人数据里（如：商贩守车不追、混混主动追击）

### 5.6 关卡与剧情（chapter/）



* 每章 = 1 个 JSON：地图 + 我方出场 + 敌人 + NPC + 目标 + 事件 + 奖励

* 目标类型：全灭敌人 / 击破 Boss / 坚守 N 回合 / 保护 NPC / 到达地点

* 事件系统（触发器 → 动作）：


  * `回合开始` → 剧情对话 / 增援

  * `单位进入区域` → 触发事件 / 开门 / 发现道具

  * `敌人数量 ≤ N` → Boss 狂暴 / 第二波增援

* 对话：对话脚本（台词 + 立绘 + 打字机效果），可嵌套分支（P1）

### 5.7 成长与进度（meta/）



* 战前准备：编队、道具整理

* 结算：经验 / 金币 / 掉落 / 剧情推进

* 存档：章节解锁 + 全单位状态（localStorage JSON）

* 死亡模式（等用户定夺）：经典 = 永久阵亡（删角色数据）/ 休闲 = 退场本章、下章回归

### 5.8 角色选择与双线（route/）



* 标题画面 → 选男主 / 女主 → 独立存档位

* 双线共享序章骨架（失踪同学 → 线索对话 → 校外两战 → 反转 → 悬念），角色 / 台词 / 线索不同

* 数据结构：`data/routes/male.json` / `female.json`（共享模板 + 差异覆盖）

* 双线互藏信息：男线见 "媒介物"、女线听 "声音"，拼合才得完整谜团 → 复玩价值

### 5.9 自由活动与明雷遇敌（overworld/）



* 安全区（教室 / 走廊 / 校门内）：自由走动 + NPC 交互对话 + 剧情推进 + 恢复

* 危险区（校外街道等）：敌人可见（明雷），带警戒圈与巡逻路径，接触触发战斗，可绕行

* 场景转场：安全区 ↔ 危险区（校门为边界演出）

* NPC 交互：头顶气泡提示 → 靠近交互 → 对话演出

### 5.10 对话演出（dialog/）



* 半身立绘左右站位 + 底部对话框 + 名字标签 + 头像小框 + 打字机效果

* 说话方立绘高亮 / 浮动；情绪变化切换表情立绘

* 关键剧情：全屏演出（特写、音效、画面抖动）

### 5.11 战斗接入流程



* 明雷接触 → 切战斗地图（棋盘）→ FE 回合战 → 胜利（经验 / 掉落，返回探索）/ 失败（教学关回安全区，正式关 Game Over 读档）

* 序章教学战：战斗 1 教移动 / 攻击，战斗 2 教地形 / 道具 / HP 危险判断

### 5.12 道具系统（P0 简单版）



* 最小闭环：**击败掉落 → 背包持有 → 战斗 / 探索使用 → 数值生效**；P0 不做商店 / 装备 / 合成

* 分类（P0）：消耗品（恢复 / 临时增益，用后消失）、关键道具（剧情用，不可使用 / 丢弃）

* 掉落：敌人数据配 `drops:[{item, chance}]`，击败时按概率结算；P0 结算时直接入背包并弹“获得道具”提示（不掉棋盘实体）

* 背包：同类堆叠计数，序章不设容量上限

* 使用：战斗中走“行动菜单 → 道具 → 目标”，消耗本回合行动；自由活动走“菜单 → 背包”；恢复不超 HP 上限，临时增益回合末清除

* 序章道具：烤肠（商贩掉落，回 12 HP）、混蛋汽水（混混掉落，回 6 HP + 本回合攻速 +3）、可疑零食（章末关键道具，不可用）

* 数据：`data/items.js` 统一配置（id / 名称 / 类型 / 效果 / 可用场景 / 堆叠上限），敌人表配掉落

### 5.13 武器系统（P0 简单版）



* 字段：id / name / type（近战 / 远程）/ might 威力 / hit 命中 / crit 必杀 / range 射程 / weight 重量

* P0：单武器槽、无耐久、无商店、战斗中不切换；单位用 `weapon` 字段引用武器 id；伤害复用 §5.4 公式（力量 + 武器威力 − 防御）

* 初始武器【新手铅笔】：近战 / 威力 4 / 命中 95 / 必杀 0 / 射程 1 / 重量 1，双主角自带、P0 无限使用

* 武器路线（P1+）：子骁 新手铅笔 → 练字毛笔；予诺 新手铅笔 → 单词卡（远程）；敌用 可疑零食（投掷）/ 练习册卷棒（近战）

* 数据：`data/weapons.js`

### 5.14 美术资源管线（现成库 + AI 定制混合策略）



* 场景瓦片：用现成 16×16 现代素材包，不从零画——LimeZu Modern Interiors / Exteriors（免费版可商用、完整版署名可商用）、Verdant 21 School（付费完整校园）、Seoul School Mini（免费教室小物）、Cozy City（现代街道）；CC0 兜底用 OpenGameArt / Kenney

* 角色素材：7 个具名角色的头像 / 立绘走 AI 提示词库定制（保人设）；行走图先用免费包占位（gegx WALK PACK PIXEL、kettoman 32×32 三人包），再用 Aseprite / LibreSprite 按人设精修

* 道具图标：AI 生成（GDD §8.5 提示词）；UI 框 Canvas/CSS 九宫格自绘

* 渲染技术：Canvas `imageSmoothingEnabled=false`、CSS `image-rendering: pixelated`、整数倍缩放

* 中文像素字体：方舟像素字体（OFL，简体首选）/ Cubic 11（OFL 备选）；Zpix 商用需单独授权，暂不用于商业发布

* 工具链：Tiled（免费地图编辑，导出 JSON）、Aseprite（付费）/ LibreSprite（免费）

### 5.15 音频系统（BGM / SFX / MIDI）



* 推荐档：CC0 芯片音乐存 ogg，HTMLAudioElement 循环 + 统一 AudioManager（场景切换淡入淡出、BGM/SFX 分轨音量、静音、首次交互后解锁音频）

* MIDI 备选：Tone.js（MIT）+ @tonejs/midi 解析 .mid 合成播放（体积极小），或 timidity（WASM + libtimidity）直放

* BGM 场景配置：标题 / 教室（轻松）、街道（悬疑）、战斗（紧张：Juhani Junkala《5 Chiptunes Action》CC0）、反转（spooky ambient）、胜利 jingle（Kenney CC0）

* SFX：Juhani Junkala《512 Sound Effects 8-bit》CC0、Kenney《RPG Audio》CC0（选中 / 攻击 / 命中 / 获得 / 翻页 / 开门 / sting）

* 授权纪律：`data/credits.js` 逐首登记名称 / 作者 / 协议 / URL，CC0 与 CC-BY 分开；不用来源不明的免费 MIDI 站曲目

## 8. 开发路线（垂直切片优先）



| 阶段        | 内容                                      | 验收                           |
| --------- | --------------------------------------- | ---------------------------- |
| P0-0 骨架   | Vite + Canvas 主循环 + 场景状态机 + 一张测试地图      | 页面能跑，相机可移动                   |
| P0-1 核心循环 | 网格 + 移动范围 + 攻击范围 + 回合管理 + 简易 AI + 基础 UI | **1 张地图完整打通 "移动→攻击→敌回合→胜负"** |
| P0-2 战斗完整 | 伤害 / 命中 / 追击 / 必杀 / 经验升级 / 道具 / 地形      | 战斗手感与数值成立                    |
| P1-1 探索   | 自由活动 + NPC 交互 + 明雷遇敌 + 区域转场             | 教室→校门→街道可走动、可对话、可撞怪          |
| P1-2 演出   | 对话系统（立绘 / 气泡 / 打字机）+ 事件系统 + 章节切换 + 存档   | 可完整演出序章剧情                    |
| P1-3 内容   | 双线序章（男 / 女）按 GDD 落地 + 头像 / 立绘入包         | 序章双线可完整通关                    |
| P2 打磨     | 音效 / 动画 / 平衡 / 移动端适配 / 后续章节扩展           | 完整可玩                         |

**建议先做 P0-1 垂直切片**：1 张地图、3 个我方单位、3 个敌人，跑通全部核心机制，再铺内容。
