# 第二幕战斗地图绘制指南（ch10 ~ ch19）

## 一、通用约定（务必先读）

1. **源工程目录**：`docs/map/tiled_project/`，每关一个 `.tmx`，已挂好 7 套 48×48 图集，`firstgid` 与游戏运行时 `src/systems/tiled_map.js` 严格一致，**请勿改动 `<tileset>` 标签**。
2. **四层结构**（每关 `.tmx` 均已就位）：
   - `Background`（layer 1）：地面/地板铺底砖。
   - `Decoration`（layer 2）：桌椅、货架、围栏、货物、旗帜等可踩/半遮挡装饰。
   - `Spawns`（objectgroup 3）：出生点（已按下方坐标放置，**先玩家后敌人**）。
   - `Collisions`（objectgroup 4）：空气墙碰撞盒（**留空待你绘制**，画了才会挡路）。
3. **当前底砖为「室内房间框架」占位**（边框 GID 81~147 + 地板 114），仅供打开时看清格子；请按下方每关「场景」与「绘制建议」重画为对应地貌。
4. **绘制完成后回写游戏**：运行 `node tools/sync_tmx_levels.cjs`，会把瓦片/碰撞/出生点同步回各 `src/data/chapters/chXX_battle1.js` 的 `tiledData`。
5. **坐标单位**：逻辑格（1 格 = 48px），左上角为 `(0,0)`，x 向右、y 向下。表格中坐标均为逻辑格。

### ch10_battle1 —— 省博展厅遭遇战（第11章 省博惊魂）
- **场景**：省博物馆「二号中央展厅」，室内。中央有防弹玻璃展柜（古瓷罐已碎），四周有红绒隔离带、解说立牌。
- **尺寸**：16×10（室内）
- **我方 6 人**（左侧）：
  - 张子骁/石予诺(2,3)、张瀚瑜/陈品璇(2,4)、范文默/何妍熹(2,5)、张希哲(3,3)、覃瑞怡(3,4)、朱晏泽(3,5)

  - 黑衣死士×3 (13,3)(13,4)(13,5)、狂暴保送生×2 (14,3)(14,4)
- **绘制建议**：展厅大理石地板；中央偏右放 2~3 个展柜/立柱作障碍，四周留走道；边框可用红绒隔离带表达「不得靠近」。
