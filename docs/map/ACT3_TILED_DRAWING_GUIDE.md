# 第三幕战斗地图绘制说明

开工目录：`docs/map/tiled_project/`。**主线必画 10 张**：ch21、ch22、ch23、ch24、ch25、ch26、ch27、ch28、ch29、ch30。全部地图均已初始化合规的 48×48 模板、标准图层、出生点与通路检测。

## 先看这四条

1. 当前战斗系统严格基于 **1 逻辑格 = 1 个 48×48 瓦片**，TMX 的 `tilewidth/tileheight` 均为 48。Tiled 打开工程时请开启视图网格并开启 **Snap to Grid（吸附到网格）**。
2. 每张地图标准包含四层结构：
   - `Background`（地面底砖层）
   - `Decoration`（装饰物、植被、货柜、机器管道等覆盖层）
   - `Spawns`（单位出生点对象层，48×48 矩形）
   - `Collisions`（不可通行障碍与空气墙，矩形对象）
   **请务必保持 Spawns 中对象的原有顺序和总数**：前 N 个对应表中我方（按六人组顺序），后 M 个对应敌方（按 Boss/精锐/小兵顺序）。拖动调整位置即可，**不要删除后新建、也不要通过排序改变对象次序**。
3. 视觉上有实心墙壁、深水死角、高台边缘、发电机箱等不可通行之处，需在 `Collisions` 绘制矩形；只画在 `Decoration` 瓦片层不会产生物理阻挡。浅水、掩体、高台等可站立地形可新建 `Zones` 对象层，按对象名配置为 `掩体`、`高地`、`泥泞` 等。**双方出生区之间必须保留至少 2 格宽度的连通路线，出生点绝对不可与 Collisions 矩形相交**。
4. 每绘制完一张地图并保存后，运行对应命令回写关卡 JS：
   ```bash
   node tools/sync_tmx_levels.cjs ch21_battle1
   ```
   （批量同步可直接无参数运行：`node tools/sync_tmx_levels.cjs`）。脚本会自动校验图层有效性、网格对齐、出生点数量与双向连通路径，通过后才安全写回 `src/data/chapters/`。

## 关键战役机制与关卡绘制特别注意

1. **ch22 九号码头（徐老师参战）**：
   - 本关我方为 7 人部署，徐老师身先士卒。码头集装箱不要把过道缩窄至 1 格死角，建议在中央保留 2~3 格宽阔的集装箱夹道以供两翼包抄。
2. **ch27 逆行光门（血肉长城）**：
   - 场景正中央 `(8, 4)` 至 `(9, 7)` 区域是通往 2026 年的时空逆行光门。建议在 `Collisions` 中将光门两侧固定机组封闭，留出正面 2 格防御通道，契合“一夫当关万夫莫开”的剧情悲壮感。
3. **ch29 斩断神明枷锁（破除神经柱）**：
   - 敌方阵地中央为神格化阿瑶，两侧为神经中枢立柱。立柱具有反震或高抗性，地图设计上在阿瑶前方留出穿插位，使近战能切到立柱，远程能策应治疗。
4. **ch30 终局决战（因果核心湮灭）**：
   - 终焉舞台无边界坠落感（四周可用半透/黑空地砖或障碍阻隔）。Boss 裁决核心位于最内侧，近卫机甲拱卫。请确保所有角色至少有 2 条通向裁决核心的通路。
