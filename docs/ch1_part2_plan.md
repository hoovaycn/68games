## 一、需求背景与目标定位

当前游戏进度已跑通序章前半段（教室点名 → 街道流动商贩战 `ch0_battle1` → 巷口混混战 `ch0_battle2` → 同学家异变现场 `scene_home`）。
按照 GDD 第 5 节规划，第一章后半段是**剧情情绪最高潮与首场多人体战棋**的关键转折：
1. **剧情推进**：两位初始队友（男线张瀚瑜 / 女线陈品璇）撞门赶到支援；打醒异变同学；深夜主角家留白收尾。
2. **重磅新增 UI 组件**：**【新角色加入弹窗组件】（`JoinPartyModal`）**。
   - **严格约定**：出现在**剧情环节**（剧情对话推进时或场景转场结算时），**绝不在战斗格子内突兀加入**。
   - **视觉要求**：重点强调伙伴加入（仪式感、金/橙醒目色系、加入音效）、半身精美立绘展示（自动滤除洋红底）、完整展示人物档案与战斗定位（姓名、班级/外号、定位/职业、初始武器、特长/个人技、生动背景生平），支持键盘 Space/Enter 或鼠标点击关闭继续推进剧情。
3. **首场 Boss 战 `ch0_battle3`**：
   - 室内战（范文默家 / 何妍熹家客书房混搭）。
   - **双人协同战**：主角 + 刚刚入队的初始队友共同出战（首度打破单人走棋模式）。
   - **打醒机制**：高 HP、疯狂自言自语（公式/音阶干扰），击败判定为物理唤醒神智而非击杀。
4. **两段入队节奏**：
   - 第一处入队：s5 队友撞门支援对话后，弹出【张瀚瑜 / 陈品璇】加入界面 → 紧接着进 Boss 战。
   - 第二处入队：s6 战后恢复说漏嘴后，弹出【范文默 / 何妍熹】加入界面 → 收下可疑零食关键道具。
5. **第一章终章闭环**：s7 深夜台灯下盯零食留白（吃没吃悬念）→ 触发第一章通关结算与章节存档 `CP_CHAPTER`。

### 1. 新增 UI 组件：`src/ui/components/join_party_modal.js`
遵循项目中 `victory_modal.js` 与 `combat_exchange.js` 的成熟组件范式：
- **容器与背景**：960×540 居中卡片，全屏暗调半透明遮罩（`rgba(8, 10, 16, 0.85)`）+ 温暖羊皮纸金色内框卡片（720×400）。
- **顶部荣耀横幅**：金色烫印缎带风格，大字标注「新伙伴加入队伍！」（NEW ALLY JOINED!），带出场光芒微动效。
- **左侧立绘区**：
  - 展示 240×320 半身像，直接读取 `assets/art/{unitId}_default.png`。
  - 自动通过 `assetLoader` 进行洋红底（#FF00FF）色键抠图，背景衬以淡色柔光圆盘。
- **右侧档案信息区**：
  - **姓名与称号**：例如「张瀚瑜」·「六 8 班学习委员」（古灵精怪的情报先锋）。
  - **战斗职能与定位徽章**：如「战术支援 / 魔法干扰」、「前排肉盾 / 强力突击」等标签。
  - **基础属性与专精**：HP / 攻击 / 防御 / 移动力成长评级，初始随身法宝（如粉笔头、篮球等）。
  - **特长/个人技（Personal Skill）**：个人技名称与机制简述（如《古怪笔记》、《八卦传话》）。
  - **生动背景简介（Bio）**：提取自 `UNITS` 配置，展现 11-12 岁小学生的人设趣味。
- **底部交互区**：
  - 高亮确认按钮「【确认加入并继续】（Space / Enter）」，鼠标悬停亮起，支持点击与快捷键。
- **生命周期**：
  - `show(unitConfig, onConfirm)`：传入单位配置数据（来自 `UNITS`）与确认后的继续回调。
  - `render(ctx)`：每帧自增虚拟时钟，提供温和呼吸浮动感。
  - `handleClick(x, y)` / `handleKeyDown(e)`：拦截剧情按键，避免事件穿透。

## 四、关键边界与安全红线检查

1. **红线约定**：入队弹窗**严格仅在剧情阶段弹出**，绝不与战棋格子、战斗行动混杂在一起。
2. **美术资源安全**：立绘与背景图片全部复用本地已确认交付的高清资产（如 `assets/art/zhanghanyu_default.png`、`assets/art/fanwenmo_corrupted.png`、`assets/backgrounds/bg_home_mc.png` 等），洋红底自动色键处理，不新增未有依赖。
3. **双线一致性**：男女线在第一章各自独立触发本线专属配角（男线：张瀚瑜+范文默；女线：陈品璇+何妍熹），数据结构与流程接口保持绝对对称。
4. **存档健壮性**：队友加入与战后打醒写入 `gameState.party`，触发 `CP_SCENE` / `CP_BATTLE_WIN` 自动写档，防止刷新掉人。
