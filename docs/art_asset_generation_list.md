# 补图清单

规则统一如下：

- 角色立绘都按到腰部构图
- 角色立绘都放 `assets/art/`
- 对应头像放 `assets/portraits/`
- 角色立绘全部是 `FF00FF` 背景
- 背景图放 `assets/backgrounds/`
- 背景图不要 `FF00FF` 背景
- 角色类资源统一补 4 个文件：
  - 标准立绘：`xxx.png`
  - 2x 立绘：`xxx@2x.png`
  - 标准头像：`xxx.png`
  - 2x 头像：`xxx@2x.png`
- 背景类资源统一补 2 个文件：
  - 标准背景：`xxx.png`
  - 2x 背景：`xxx@2x.png`

你照着“资源名 / 要存的文件 / 提示词”生成即可。
