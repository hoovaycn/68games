## 三、短简介（约 100 字内，商店卡片 / 列表页通用）

《附小六8异闻录》是一款校园悬疑题材的回合制战棋游戏。你扮演六8班的一名小学生，发现同学在一夜之间被“想变厉害”的念头吞噬，开始整夜刷题、练琴，眼神发青。你要拉上几个讲义气的伙伴，用文具、知识和操场上的家伙事儿，在九章的悬疑故事里把伙伴一个个“打醒”，并揭开校门口荧光零食背后的真相。

## 四、标准商店简介（约 300 字，Steam / itch.io 通用）

六8班最近有点不对劲。

先是范文默整夜刷高三电磁学，一边哭一边念叨“它们要来了”；接着何妍熹抱着长笛练同一个音到凌晨三点，关灯就喊“外面有脏东西”。一切的起点，是校门口那个推着小车、笑得像假人的大叔，和他手里那包会发光的荧光零食。

《附小六8异闻录》是一款校园悬疑 SRPG。你将在张子骁与石予诺两位主角之间二选一，用火焰纹章式的回合制战棋，把被“焦虑”吞噬的同学一个接一个打醒——不是打死，而是唤醒。武器是铅笔、练字毛笔、橡皮、弹珠、操场上的篮球；对手是走火入魔的同窗、被污染的老师和藏在阴影里的“它们”。

剧情驱动，探索与战斗交替推进；双主角双线开局，第一章不同，二周目信息互证。当“想变厉害”的念头变成怪物，请记得：最该被守护的，是一个不被焦虑绑架的童年。

## 五、长简介 / “关于游戏”（Steam 详情页）

### 故事
六8班的早读点名，少了一个人。徐老师把你叫出教室，给你看家长发来的微信——内容日常，却让人脊背发凉。你顺藤摸瓜，在校门口撞见那个推小车的商贩，正把一包荧光零食塞进同学手里。

同学开始整夜刷题、闭眼练琴，嘴里念叨着不属于小学生的高中公式与音阶。他们说，是“它们”在看着。而这一切，都指向一句再熟悉不过的念头——**吃一口，是不是就能考高分？**

### 玩法
- **像下棋一样打架**：轮到你走，一格一格挪，打之前就能看清这一下能打中多少、伤多少，不靠运气瞎猜。
- **选张子骁还是石予诺？** 两位主角，开场的故事不一样：一个讲义气的棋王，一个爽利的美术课代表。选谁都行，二周目换个主角，还能看到上一轮漏掉的另一面。
- **越熟悉的东西越瘆人**：你天天攥在手里的铅笔、橡皮、作业本、体测表，一夜之间全变得不对劲——最普通的东西，藏着最贴脸的诡异。
- **一章一个来**：先在教室、校门口、巷子里转悠找人、套话，摸清情况，再上操场、仓库摆开阵势，跟变怪的同学真刀真枪打一场。

### 主题
不喊口号，用故事讲一句：**别让焦虑和攀比，吃掉童年。**

## 八、各平台发布要点

### 1. itch.io
- **上传**：打包后文件夹压缩为 `.zip`，在项目页面勾选 **Play in browser**，即可网页在线玩。
- **简介**：用上文“短简介”或“标准简介”。
- **标签**：套用英文标签；封面图建议一张 630×500 的主图 + 若干截图。
- **补充**：可设置“付费下载 + 网页免费试玩”，是积累早期玩家的常用做法。

### 2. Steam
- **前置**：缴纳 100 美元 Steam Direct 费，完成开发者注册与税务信息（W-8BEN）。
- **简介**：短简介 + “关于游戏”长简介，可直接套用上文。
- **必备素材**（尺寸规范，需单独制作）：
  - 商店页眉大胶囊图 Header Capsule（616×353）
  - 主胶囊图 Capsule（616×353 / 231×87 / 467×181 多档）
  - 竖版封面 Vertical Capsule（600×900）
  - 5 张以上游戏截图（建议 1280×720 或 1920×1080）
- **存档**：开启 Steam **Auto-Cloud**，指向 `%APPDATA%/游戏名/`，即可实现云存档，无需改代码。

### 3. Indienova（独立游戏社区）
- **入口**：`https://indienova.com`，国内直连，独立游戏玩家聚集地。
- **发布**：投稿“试玩 / 开发日志”，用“标准简介 + 卖点清单”，配 3–5 张截图。
- **价值**：积累核心玩家、收集反馈，为 Steam 发售预热。

### 4. 浮生（indienova 游戏托管）/ 同类试玩聚合站
- **方式**：上传 HTML5 网页包（zip），平台自动托管，玩家在线试玩。
- **文案**：短简介即可。

### 5. TapTap
- **发布**：走国内开发者入驻，上传安装包或网页试玩链接。
- **文案**：短简介 + 卖点清单 + 截图；标签用中文标签。
- **注意**：国内平台需留意版号/内容合规，Demo 试玩通常门槛较低。

### 6. 静态托管（快速发链接给朋友 / 测试）
- **Cloudflare Pages / Gitee Pages / GitCode Pages**：将 `npm run build` 产出的 `dist` 目录拖拽或推仓库上传，生成公开网址，朋友点开即玩。
- 说明：这些平台本身无需“简介”，只需一个游戏名与分享语即可；分享语直接套用“一句话定位”。
