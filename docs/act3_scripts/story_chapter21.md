# 第21章剧本：《神医的茶香》

## 流程结构
- `ch21_scene_clinic_warmth`: 新学期开学，毕业班开展心理与脑科健康普查；主角团在排队中推开崇文楼咨询室的门，初见温婉从容的省城专家「苏晚医生」，茶香温热、安神糖甜中带涩
- `ch21_scene_dock_suspicion`: 咨询结束走出走廊，意外撞见教务处转角徐老师与刘老师的激烈争执；海峰突击水闸扑空受处分，徐老师被疑暗通密报，矛盾激化
- `ch21_scene_alley_ambush`: 雨夜尾随，徐老师疾步隐入城西废弃旧水闸铁门；易拉罐声响惊动暗哨，亡命混混阿彪率众前后合围，铁棍逼近，徐老师被迫闪入暗影，暗巷死斗一触即发
- `ch21_battle1`: 水闸暗巷突围战（主角团 VS 三号船盯梢头目阿彪与青眼苦力）
- `ch21_scene_night_after`: 击溃亡命混混，泥水里翻出带血的集装箱交割单；督导章与徐字签字引爆伙伴激烈争辩，决意夜探九号码头查清真相
