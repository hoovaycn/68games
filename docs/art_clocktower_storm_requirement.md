# 第二十章巨魔登场：阴云钟楼背景需求

给美术：以现有 `assets/backgrounds/bg_clocktower_summit@2x.png` 为**构图母版**，做同场景的阴云版本。不是新地点，也不是结局的古运河岸边。请同时参考同名标准版，确保逐句切换背景时钟面、彩窗、窗框、柱子、齿轮和镜头角度不跳动。

## 交付接口

- `assets/backgrounds/bg_clocktower_storm@2x.png`：1920 x 1080，PNG，16:9。
- `assets/backgrounds/bg_clocktower_storm.png`：960 x 540，PNG，16:9，与高清版同构图。
- 文件放进现有 `assets/backgrounds/`。剧情已在沈崇礼扳下启动杆、阴云遮光的那一句切到高清版；巨魔出场和决战前的对白一直使用阴云版。击碎核心后，剧情自动切回原 `bg_clocktower_summit@2x.png`，不用另外制作胜利版。
- 保持原图的细像素 JRPG 风格和像素密度，边缘利落；可压缩 PNG，但不要糊掉彩窗与齿轮细节。高清版尽量控制在约 2 MB。

## 画面

参考现有钟楼图：中央巨大的金色钟面、左右高彩窗、右窗外强烈日光、正面的齿轮和天花板结构都保留在**原坐标和原比例**。把窗外蓝天和直射阳光改为厚重翻卷的铅灰色乌云，右侧日光被完全遮住；室内明显变暗，金色铜钟只剩冷光反射，彩窗透进少量暗蓝紫色光。窗外可带一点黑紫色毒雾，但不要画成整幅纯黑；钟面轮廓、立绘和对白仍须清楚可辨。让玩家感到同一座钟楼突然暗下来，巨魔即将现身。

**不要把巨魔、沈万廷、沈崇礼、药罐或人物剪影画进背景。**巨魔已有透明立绘 `assets/art/boss_colossus_opium_god@2x.png`，会在阴云版背景上由剧情单独显示。不要添加绿色魔核、巨大手臂、文字、闪电特效、UI 或水印，以免跟立绘的位置和动画对白冲突。底部约三分之一被对话框覆盖，两侧会有人物立绘；钟面与窗外阴云变化应在中上区域一眼可见。

交付后请检查：普通钟楼 -> 阴云钟楼 -> 普通钟楼逐句切换时，建筑结构是否完全对齐；两版尺寸是否正确；阴云版是否够阴森、但仍读得清场景。背景未交付前，巨魔相关对白会使用剧情系统默认底色，不会把普通晴天钟楼当作阴云版。
