## 第四章《她是谁》——敌人是谁（重点说清）

### 剧情：坏教练派人闯校，张希哲在过场里异化（不占战斗中途）
- 第二章被搅了局的**坏教练不甘心**（他本人本章不出场，留到第五章当 boss），大考前派人来本校"清场 / 加料"：一批**喝了异化饮料的外校体育生**闯进操场 / 放学后堵在校门口叫阵，要强拉本校学生去"集训"、硬塞饮料，学生有受伤危险。
- **张希哲的异化放在战前过场里演完**：他眼看同学要被围、主角要吃亏，趁乱抓起一瓶异化饮料灌下去，心想"我变强就能护住大家"；过场里他爆种、一个人清了场，随即敌我不分、深度异化，转头和外校体育生站到一起，成了挡在主角团面前的敌人。
- 众人投鼠忌器、不敢对张希哲下手时，墙角黑影走到灯下——黑影女第一次露正脸=新来的道法刘老师，和徐老师并肩，点明："我们大人的话它不听。能把他拉回来的，只有你们——打醒他，别打死他。"

### 敌方配置（战斗开场即全在，三类）
1. **异化外校体育生（杂兵 × 若干，可打）**：第二章那批的加强版，数量多、攻高、没理智。
2. **带头的外校体育生队长（小头目 / 精英怪）**：领着人冲。
3. **异化的张希哲（敌方小 boss，要打醒的自己人）**：攻高、会冲阵，是本章核心目标——**打赢他 = 把他打醒**（沿用打醒范文默、体育老师、朱晏泽的成熟逻辑，不是打死）。

### 胜利条件
- 击败 / 打醒异化张希哲，并清掉队长和杂兵。
- 打醒演出：把张希哲打到临界，由**覃瑞怡冲上去喊他名字**触发"唤醒一击"（剧情一击，覃瑞怡负责喊）；不做"不可打、近身 N 次"的特殊关，就是一场正常的、打醒自己人的 boss 战。
- 徐老师前排护人开路、道法刘老师给镇定 / 指挥（道法刘老师本章现身入队，剧情辅助位）。

### 战后
- 张希哲瘫坐回神、没事，正式归队。
- 道法刘老师亮底牌（点到为止）：这东西很多年了、隔几年来一次、毕业班是重灾，她追了很多年；徐老师那些"可疑"动作（捡瓶子、锁抽屉、名单、夜会）当场一一重读为救人。
- **指认上线**：范文默 / 何妍熹认出接头商贩（校门口推车的，不是一个人在干）；被打醒的外校体育生指认饮料是**坏教练**给的。→ 引出第五章打上据点。

## 第五章《全国第一》——敌人：商贩团伙 + 混混 + 坏教练

### 敌方配置（按用户设定，真打）
- **多个商贩**：第一章打跑的那个只是其一，据点里是一伙推车的（远程扔辣条 / 撒零食干扰，第一章教学战那种套路的成群升级版）。
- **更多高年级混混**：第二章巷口那种的加强版，数量、血量都上一个台阶，负责看场子。
- **坏教练（本章 boss）**：给外校体育生供饮料的人，攻高、会给小弟"灌饮料"临时强化 / 召唤异化体育生；是本章要打倒的核心。
- 关卡结构建议：先清外围商贩 + 混混（一两波），再打坏教练（boss 战）。

### 战前 / 战中的"对质"（可做机制，不喧宾夺主）
- 场上散落证据道具（当年不及格的成绩单、旧奖状 / 金牌、十几年前同款老包装、年轻时合影），走位拾取、当场"出示"可削弱坏教练 / 让被召唤的异化体育生提前醒转（少刷怪）。

### 战后揭身世（娓娓道来，受害者→加害者）
- 打醒 / 打瘫后，两条线平行交代：
  - 商贩当年是学渣，用了异化零食成全国第一 / 状元 / 奥赛金牌【头衔待定】；
  - 坏教练当年是体育差生，用了异化饮料成全国少年冠军 / 健将。
  - 都真得到过巅峰，也都被掏空——除了"赢"什么都不会、巅峰过去空空如也，如今一个推车、一个当野鸡教练，靠继续发东西找存在感。**曾经的全国第一，如今在小学门口卖烤肠。**
- 反噬与抉择（建议保留）：被戳穿时两人身上异化暴走（"它们"要灭他们口），胜利条件追加"把这两个害过孩子的人也喊回来"——救递东西的手，坐实"加害者也曾是受害者"。
- 章末钩：货不是他们做的，也没见过做东西的人，"每隔一阵子自然有路子送来""上面给的，没见过人"。**到底谁做的？**（玩家强烈期待大 boss，为六、九章红鲱鱼蓄势。）

## 第六章《家长会》——防守战到底怎么打（重点讲清）

### 一句话
**家长不能打；打的是"被家长当场逼出来 / 喂出来的异化学生"。赢法不是打光谁，而是拦住发样品、把异化的孩子救醒给家长看，拖到大人们自己看不下去、散会。**

### 为什么会打起来
- 家长会上，带头家长力主"引进"那种零食 / 饮料，现场摆了样品、要当场给孩子"试效果"；有被带来做样板的学生、和抢着试 / 被家长逼着试的孩子，**当场异化失控**。东西一旦批量发到学生手里，全校就完了——主角团必须在会场里拦下来。

### 谁打谁
- 我方：主角团 + 徐老师 + 道法刘老师。
- 敌方（可打）：**当场异化的学生**（失控的样板学生、试吃后异化的同学）。
- 不可打：所有家长（红线）。**带头家长是"关卡机制 / 时钟"，不是血条**——他每回合在台上施压：强行发样品（给敌方增员）、给全场异化学生加攻、给我方叠"压力"debuff、动摇围观家长的信任。

### 怎么算赢（三个目标同时做）
1. **拦发放（占点 / 拦截）**：走位堵住发放点、插到家长和学生之间，把样品踢飞 / 收走；限定回合内每漏掉一包，下回合就多一个异化学生敌人（漏得越多越难打）。
2. **救孩子（喊回）**：近身把异化的学生一个个喊醒（复用机制）；每在家长面前成功救回一个，**累积"动摇槽"**。
3. **护住人**：打 / 拖住失控学生，别让他们伤到家长和同学（讽刺感：孩子反过来护着逼自己的大人）。
- **胜利条件 = 动摇槽攒满 / 撑够回合**：围观家长亲眼看见自家孩子异化的惨状，舆论反转，家长会被迫中止。
- 不需要、也不能把带头家长"打死"。

### 结局与钩子
- 样品被收缴、家长会不欢而散，表面拦下；但带头家长撂狠话，镜头给到有家长偷偷把样品塞进包里带回家。
- 章末钩：他一个电话就能调货、对怪 logo 毫不意外、看道法刘老师的眼神像旧识——**他会不会就是大 boss？**（红鲱鱼，九章回忆加深、第二幕再翻）

## 第七章《大溃败》——敌人：满屏异化 NPC（必败）

- 我方：**常驻班底全员开场**（主角团 + 张希哲、覃瑞怡、朱晏泽 + 徐老师、道法刘老师）——这是班底收齐后第一次、也是唯一一次全员并肩的恶战。
- 敌方：**海量异化 NPC，全是熟脸**（救过的同学、甚至队友；自愿的、被骗的混在一起）。
- 人性群像（剧情重点）：有人替胆小的同学收下糖"替你扛"、有人装异化偷偷藏人、有半异化的把主角推进器材室自己反锁挡门外；也有人抢糖、出卖没异化的人换"奖励"、笑着劝好友"你也吃吧，吃了就不难受了"。
- 机制上**不可取胜**：胜利条件=撑够 N 回合 + 护送未异化者撤到安全点（道法教研室 / 器材室），到点剧情强制失守。战中让队友一个个异化 / 主动断后（张希哲、朱晏泽、覃瑞怡先后倒下，或为护住别人被荧光淹没），**退守进器材室时只剩主角团 + 徐老师 + 道法刘老师**——班底在玩家眼前被逐个打散，这场失败才有重量，也才衬得出第十章把他们一个个拉回来的分量。
- 揪心抉择（建议）：有人劝主角"就喝一口，变强才能救更多人"，主角仍选择不喝。
- 章末：荧光在门外一片片亮起，道法刘老师开口："……很多年前也有这么一个晚上。那时候在那间教室里的，是我和徐老师。"坠入回忆。
- 【待定】幸存"三人组"=主角 + 第一章两个初始搭档（男线张瀚瑜、范文默 / 女线陈品璇、何妍熹），与当年三人组镜像。

## 第九章《从前那一班（下）》——神秘"家长样"的 boss，留悬念到下一幕

### 顺线摸网
- 为拉住第三个好友、查来源，俩女孩顺着"谁给你的"往上摸，救一个问一句，第一次意识到背后像有一张网 / 一个**组织**在系统发放。

### 神秘 boss：本人下场真打，打赢了但人跑了（按用户）
- 据点最深处，那个**"家长样"的神秘男子本人深度异化、亲自下场**——这是回忆里的真 boss，给足 boss 战分量（高血量 / 多阶段 / 会给全场异化学生加 buff 或召唤，压迫感拉满），好歹是个 boss。
- 守红线的方式：孩子打的是他的**异化形态**（同第二章魔化体育老师的先例——打的是"异化的他"，不是普通家长本人）；视觉仍走统一语言（青蓝发光眼、冷青调、异化程度更深、半张脸始终在光里看不清），不怪物化、不长异物。
- 他全程逆光、看不清全脸，只给一个姓 / 一个家族轮廓。
- 年龄钩（按用户提示）：当年这个成年男子如今已是祖辈；今天第六章那个带头家长，**疑似是这户人家的下一代，像个世袭家族**。回忆里把这味道拍足，但**不确认、不揭脸、不解释**。
- 回忆战3：俩女孩拼尽全力，**真的打赢了这个异化 boss**，他的异化形态崩解——可就在要被看清脸、被抓住的瞬间：
  - 他趁乱、借着现实大人赶到的混乱脱身，只留下背影 / 一句话 / 一个家徽式记号，**人跑了**；
  - 据点被随后赶来的大人清空，没人信两个孩子，证据全没；
  - 第三个好友最终没拉住，考完第一就"变了个人"，转学、再没回来。

## 第十章《大考》——打"异化的自己"（按用户设定，重点章）

### 核心战斗：每个人 vs 异化的自己
- 大考当天，"它们"最后一次发力，考场在精神层面扭曲成异空间——它把每个人心里"想走捷径的自己"具象成敌人：**异化的自我（影子自我）**。
- 所有**曾经异化过、被救回过的角色**（范文默 / 何妍熹、体育老师、外校体育生、朱晏泽、张希哲、覃瑞怡、商贩、坏教练……）这次都回来，各自面对一个异化版的自己，**全员收一遍"战胜自我"的弧光**。
- 关键规则（机制咬死主题）：**别人替你赢不了你的影子**。队友能帮忙清杂、牵制、撑场、喊你名字（拉人连锁的内化版），但对"你自己的异化自我"，决定性一击 / 关键选择必须由**本角色本人**完成——走到它面前，承认"我确实想过走捷径"，再选择不做它。
- 关卡形态（供研发参考，可选其一或组合）：
  - 多战线 / 车轮：依次帮每个伙伴了结他们的影子（本人站到关键位、队友护着）；
  - 最终 solo：众人的影子都了结后，**主角独自面对终极 boss=主角的异化自我**（那个"吃了零食、考了高分、却不是自己"的学酥）。这是全幕最难、也最安静的一仗。
- 打败异化自我不是否定"想变好"，而是："我想变好，我也怕输，但我不要变成一个假的我。"无面荧光影可处理为"所有异化自我的总和"，随着一个个影子被本人接纳并拒绝，它逐层崩解。

### 回到现实：集体不伸手（价值观落点）
- 精神战斗结束，回到安静的考场：每个人桌上 / 笔袋里莫名有一包异化零食，大家平静地把它推回去 / 上交，凭真本事考完。
- 发成绩（按用户设定）：有人考得好、有人考得不好、有人进步有人原地踏步，但每一分都是真的、每个人都还是自己，没有谁被拿走灵魂。学酥主角可能还是中等，却笑得踏实："我还是我，慢就慢点呗。"
- 人物下落用蒙太奇快速交代：商贩、坏教练回归平凡；带头家长依旧装睡（冷处理、不强行感化）；道法刘老师第一次走到阳光下；徐老师松一口气；那包"已丢弃的零食"正式了断。

## 幕结构（系列骨架，第二幕起复用）

**一幕 = "它们"瞄准人性的一类弱点，换一种媒介、占一个压力场、闹一轮，最后靠这群孩子的"识别 → 承认 → 喊回 → 拉人连锁"踩一次刹车。**

每幕固定节拍：
1. 新压力场 / 新风气出现；2. 新媒介流行、"真有效"、先给甜头；3. 有人异化（切面群像），主角团察觉；4. 顺线查"是谁给的"，找到受害者或红鲱鱼、不是源头；5. 一次反转 + 一次至暗（溃败 / 误解 / 回忆）；6. 主角 / 同伴面对自己的同款弱点（内心关）；7. 集体选择、拉人连锁，踩停这一轮；8. 余波收束 + 换下一幕的新苗头。

- 贯穿不变：里世界规则、道法刘老师、徐老师、主角团、"它们"、怪 logo（或变体）、受害者即加害者。
- 每幕更换：核心弱点、媒介形态、压力场、异化视觉主色 / 表现、被异化人群切面。
