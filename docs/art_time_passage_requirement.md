# 第二幕穿越通道背景：增量美术需求

用于第十五章驳船消失之后、第十六章宫廷历史画面之前的 `ch15_scene_time_passage`。这是一张独立背景，不是宫廷或虎门海滩的重画。剧情上六个孩子、海峰、徐老师和刘老师一起从现代穿越；宫廷、虎门是通道途中看到的过去，直到虎门海滩才真正落地。

## 交付

- `assets/backgrounds/bg_time_passage@2x.png`：1920 × 1080，PNG，16:9。
- `assets/backgrounds/bg_time_passage.png`：960 × 540，PNG，16:9；与高清版构图完全一致。
- 按现有第二幕背景的细像素 JRPG 画风绘制，参考 `bg_barge_altar@2x.png` 的像素密度、蓝紫暗部和金色光线。不要用粗大像素块或写实的 3D 光滑渐变。
- 在保证细节的前提下压缩 PNG 体积，优先让高清版不超过约 2 MB；不要为了体积把像素边缘压糊。无需透明通道。不要把压缩服务的密钥写进项目。

## 画面

从现代江面进入时空通道的**通道内部**：深蓝色倒卷的江水、驳船边缘消散的木板和铁链环绕画面两侧；黑紫烟雾与细金色纹路交缠，形成通向画面中上部的纵深漩涡。远处出口只隐约透出旧时海岸与帆影，不要直接画成已经到达虎门。给玩家明确的“正在穿越、还没落地”的感觉。

底部三分之一会被对话框遮挡，关键漩涡和出入口放在中上方；左右两侧要兼顾角色立绘遮挡。整张必须是完整场景背景，不要人物、脸、瓷罐、宫殿、文字、水印或 UI 边框。可参考 `bg_humen_beach_1839@2x.png` 的远处暖色光感，但主体仍以驳船图的冷色像素风为准。

剧情代码中 `ch15_scene_time_passage.bgImg` **已经指向** `assets/backgrounds/bg_time_passage@2x.png`。美术只需将两张同名 PNG 放到上述目录，重新打开游戏即可显示，无须再改剧情配置。交付后请运行剧情测试、构建并在浏览器中检查实际画面；交付前该场景会以黑底显示剧情文字，不会借用驳船背景充数。
